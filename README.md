# 布卷疵点复检与退修系统

纺织厂质检演示系统：管理布卷、织机、颜色批次、检验段、疵点类型、复检任务、退修工单和放行记录。
仅依赖 **Python 3.10+ 标准库**（SQLite + http.server），无需安装任何第三方包。

## 一条命令启动

```bash
python3 -m textile_qc            # 默认 http://127.0.0.1:8000
python3 -m textile_qc --reset    # 清空旧库，重建初检/复检/退修/放行样例
python3 -m textile_qc --port 8011
```

启动后自动：

1. 创建 SQLite 库 `data/qc.db` 与疵点照片目录 `data/photos/`；
2. 播种 3 台织机、3 个颜色批次、9 卷演示布卷，覆盖初检、复检、退修新版本、
   经理特许放行、拒收、复检超时、照片缺失等全部场景；
3. 启动网页（六个页签：布卷台账 / 检验录入 / 疵点地图 / 复检队列 / 退修进度 / 放行记录）；
4. 进程内后台任务每 30 秒扫描复检超时，自动转 `overdue` 并写入提醒。

## 核心业务规则

- **入检**：记录长度、标称长度、幅宽、颜色批次、来源机台；疵点按米数定位并附照片。
- **位置区间**：疵点位置必须落在所属检验段 `[start,end)` 内；检验段不得超出布卷长度、同版本不得重叠。
- **复检引用**：复检任务只能引用**当前检验版本**的原检验段；退修后的旧版本检验段失效。
- **复检人隔离**：复检接收人不得与该版本初检人相同。
- **接收竞争**：同一布卷同时只允许一条活跃复检任务（部分唯一索引 + `BEGIN IMMEDIATE` + 进程内锁），
  两条产线并发接收只有一条成功；完成/取消后可再次接收。
- **版本链**：退修完工后生成新版本（`supersedes` 指向旧版本），旧版本置 `superseded`、旧复检任务取消。
- **分级放行**：
  - C 级（轻微）：记录后可直接放行；
  - B 级（色差/污渍等）：逐点复检，须由非初检人复检并给出 `cleared`；`confirmed/escalated` 须退修；
  - A 级（断经等）：必须退修，新版本复检通过后才能放行；
  - 照片缺失：一票否决，补传后自动清除缺失记录；
  - 长度不足：唯一可由**经理特许**豁免的项。
- **终态保护**：已放行/已拒收布卷只读，不能改回待检，不能补照片或重开检验。
- **复检超时**：默认 24 小时 SLA；扫描转超时、写提醒，只有主任可重新派发。

## 界面

- 配色：亚麻色（底）、板岩灰（导航）、锈红（主操作/告警）。
- 布卷以**横向长度条**呈现，检验段分段着色，疵点按米数落点（A 锈红 / B 土黄 / C 灰，斜纹=照片缺失）。
- 检验录入页左侧**固定面板**常驻显示当前米数与幅宽。
- 放行状态同时使用**色标圆点 + 中文文字**（待检/待复检/退修中/已放行/已拒收…）。

## 目录结构

```
textile_qc/
  db.py        SQLite 建表与事务（IMMEDIATE）
  service.py   全部业务规则（QCService / QCError）
  users.py     账号与角色权限
  demo.py      织机/颜色/布卷演示数据与程序化 PNG 照片
  server.py    stdlib HTTP：JSON API + 静态页 + 超时扫描线程
  web/         index.html / style.css / app.js
  __main__.py  单命令启动入口
tests/         unittest 用例
```

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bolts` `/api/bolts/{id}/map` `/api/bolts/{id}/gates` | 台账 / 疵点地图 / 放行条件 |
| POST | `/api/inspection/open` `/api/segments` `/api/defects` `/api/inspection/complete` | 检验录入 |
| POST | `/api/reinspections` `/…/{id}/claim` `/…/{id}/complete` `/…/{id}/requeue` | 复检 |
| POST | `/api/reworks` `/api/reworks/{id}/finish` | 退修 |
| POST | `/api/release` | 放行/拒收（`concession` 特许） |
| GET/PUT | `/api/photos/{defect_id}` | 查看（三类岗位）/ 补传（初检、主任） |

写操作通过请求体或 `?user=` 指定操作员，服务端按角色鉴权。
